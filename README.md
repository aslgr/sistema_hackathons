# Sistema de Hackathons

Trabalho prático da disciplina de Engenharia de Software.

O projeto consiste na modelagem e implementação de um sistema para
gerenciamento de hackathons acadêmicos.

## Tecnologias previstas

- Python
- Flask
- HTML/Jinja
- SQLite

## Modelagem

- Diagramas de Sequência de Sistema (DSS)
- Contratos de Operação
- Diagramas de Interação
- Diagrama de Classes na Visão de Projeto
- Diagrama de Pacotes
